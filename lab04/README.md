## Краткая сводка

«Стек» — временная память (ячейки локальных переменных), «хип» — динамическая память (объекты).
Внутренние объекты, которые создает сам `Console.WriteLine`, не считаются.

| № | Ячеек в стеке | Объектов в хипе | Переменные в конце | Вывод |
|---|---|---|---|---|
| 1 | 1 (`a`) | 0 | `a = 5` | `5` |
| 2 | 2 (`a`, `b`) | 0 | `a = 6`, `b = 7` | `6` |
| 3 | 2 (`a`, `b`) | 0 | `a = 2`, `b = 2` | `2`, `2` |
| 4 | 2 (`a`, `b`) | 0 | `a = 7`, `b = 11` | `11` |
| 5 | 3 (`a`, `b`, `c`) | 0 | `a = 5`, `b = 5`, `c = 11` | `5`, `11` |
| 6 | 2 (`a`, `c`) | 0 | `a = 7`, `c = 7` | `7`, `7` |
| 7 | 2 (`a`, `b` — ссылки) | 2 (строки `"1"` и `"2"`) | `a → "2"`, `b → "1"` | `2`, `1` |
| 8 | — | — | — | ошибка компиляции CS0029 |
| 9 | — | — | — | ошибка компиляции CS0128 |

## Подробно

### 1. Определение переменной
```csharp
int a = 5;
Console.WriteLine(a);
```
- `int a = 5;` выделяет в стеке ячейку `a` под целое число и записывает туда `5`.
- `Console.WriteLine(a)` читает значение из `a` и печатает его.

Вывод: `5`.

### 2. Присваивание одной переменной к другой
```csharp
int a = 5;
int b = 6;
a = b;
b = 7;
Console.WriteLine(a);
```
1. ячейка `a` ← `5`;
2. ячейка `b` ← `6`;
3. `a = b` **копирует** значение из `b` в `a`: `a = 6`;
4. `b = 7` меняет только ячейку `b`. Ячейки не связаны, `a` остается `6`.

В конце `a = 6`, `b = 7`. Вывод: `6`.

### 3. Попытка обмена значениями
```csharp
int a = 1;
int b = 2;
a = b;
b = a;
Console.WriteLine(a);
Console.WriteLine(b);
```
`a = b` перезаписывает `a` значением `2`, и старое значение `1` теряется.
Затем `b = a` записывает в `b` то, что теперь в `a`, то есть `2`.

В конце `a = 2`, `b = 2`. Вывод: `2`, `2`. Обмена не произошло.

Правильный обмен — через третью ячейку `temp` (функция `Task03Swap`):
```csharp
int temp = a; // temp = 1
a = b;        // a = 2
b = temp;     // b = 1
```
Здесь 3 ячейки в стеке, вывод `2`, `1`.

### 4. Присваивание выражения, включающего переменную
```csharp
int a = 5;
int b = a + 6;
a = 7;
Console.WriteLine(b);
```
На 2-й строке вычисляется выражение `a + 6` → `5 + 6` → `11`, и в `b` записывается **результат** `11`.
Изменение `a` на 3-й строке на `b` не влияет — в `b` уже лежит готовое число.

В конце `a = 7`, `b = 11`. Вывод: `11`.

### 5. Литералы, переменные и операторы — это выражения
```csharp
int a = 5;
int b = a;
int c = a + 6;
Console.WriteLine(b);
Console.WriteLine(c);
```
- `5` — литерал, выражение со значением `5` типа `int`;
- `a` — чтение переменной, выражение со значением `5`;
- `a + 6` — оператор `+` над двумя выражениями, значение `11`.

В конце `a = 5`, `b = 5`, `c = 11`. Вывод: `5`, `11`.

### 6. Присваивание как выражение
```csharp
int a = 5;
int c = (a = 7);
Console.WriteLine(a);
Console.WriteLine(c);
```
`(a = 7)` записывает `7` в `a` и само дает значение `7`, которое затем записывается в `c`.

В конце `a = 7`, `c = 7`. Вывод: `7`, `7`.

### 7. Присваивание ссылочной переменной
```csharp
string a = "1";
string b = a;
a = "2";
Console.WriteLine(a);
Console.WriteLine(b);
```
- `string a = "1";` — ячейка `a` в стеке; объект строки `"1"` в хипе; в `a` записывается **ссылка** (адрес) на этот объект.
- `string b = a;` — ячейка `b`; в нее копируется ссылка из `a`. Теперь `a` и `b` указывают на один объект `"1"`.
- `a = "2";` — в хипе есть объект `"2"`, в `a` записывается ссылка на него.
  Меняется ссылка в `a`, а не сам объект `"1"`, поэтому `b` по-прежнему указывает на `"1"`.

Итого: 2 ячейки в стеке, 2 объекта-строки в хипе. В конце `a → "2"`, `b → "1"`. Вывод: `2`, `1`.

### 8. Присваивание `int` к `string`
```csharp
string a = 5;
```
```
error CS0029: Не удается неявно преобразовать тип "int" в "string".
```
Несовместимость типов: в переменную `string` можно записать только ссылку на строку, а `5` — это число.

### 9. Создание переменной с тем же именем
```csharp
int a = 5;
int a = 6;
```
```
error CS0128: Локальная переменная или функция с именем "a" уже определена в этой области.
```
Переменную нельзя определить второй раз (даже другим типом, например `double a = 6;` — та же ошибка).
Можно только перезаписать значение: `a = 6;`.

### 10. Имена, отличающиеся только регистром
```csharp
int a = 5;
int A = 6;
Console.WriteLine(a);
Console.WriteLine(A);
```
C# различает регистр: `a` и `A` — две разные переменные, две ячейки. Вывод: `5`, `6`.

### 11. Регистр в именах методов
```csharp
console.WriteLine("Hello");
```
```
error CS0103: Имя "console" не существует в текущем контексте.
```
Тип называется `Console` с большой буквы, имени `console` не существует.

### 12. Вывод типа через `var`
```csharp
var a = 5;
Console.WriteLine(a);
```
Тип `a` выводится из выражения `5` — это `int` (программа печатает `Int32`, это то же самое).
Вывод: `5`. Тип фиксируется при компиляции, поэтому `a = "abc";` дальше не скомпилируется
(`error CS0029: Не удается неявно преобразовать тип "string" в "int".`).

### 13. `var` без инициализации
```csharp
var a;
a = 5;
```
```
error CS0818: Неявно типизированные переменные должны быть инициализированы
```
Компилятору не из чего вывести тип: `var` требует выражение прямо в определении,
последующее `a = 5;` не помогает.

### 14. `var` от другой переменной
```csharp
int a = 5;
var b = a + 5;
Console.WriteLine(b);
```
Тип выражения `a + 5` — `int`, значит `b` тоже `int` со значением `10`. Вывод: `10`.
