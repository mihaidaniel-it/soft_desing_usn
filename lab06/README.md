Строки `проверка: ...` добавлены, чтобы увидеть значения переменных. Запуск: `dotnet run`.

## Концепты

- **`bool`** — тип-значение с двумя значениями: `true` и `false`. В консоль печатается как `True` / `False`.
- **Логическое выражение** — выражение, результат которого имеет тип `bool`.
- **Сравнение чисел**: `>`, `<`, `>=`, `<=`, `==`, `!=` — принимают два числа, возвращают `bool`.
- **Логические операторы**: `&&` (И), `||` (ИЛИ), `!` (НЕ), а также `==` и `!=` для двух `bool`.
- **Lazy evaluation**: у `&&` второй операнд не вычисляется, если первый `false`;
  у `||` — если первый `true`. Результат уже известен по первому операнду.

## Подробно

### 1. Что печатает `true`
```csharp
bool a = true;
Console.WriteLine(a);
```
`bool` хранит одно из двух значений. При выводе оно превращается в текст `True`.

### 2. Присвоение пустой ссылки к `bool`
```csharp
bool a = null;
```
```
error CS0037: Не удается преобразовать значение NULL в "bool", поскольку этот тип значений не допускает значение NULL.
```
`bool` — тип-значение, а не ссылочный тип. В его ячейке лежит само значение, а не ссылка,
поэтому `null` (пустая ссылка) туда не помещается.

### 3. Сравнение это логическое выражение
```csharp
bool a = 1 == 2;
Console.WriteLine(a);
```
`==` сравнивает два выражения и дает `bool`. `1 == 2` → `false`. Вывод: `False`.

### 4. Сравнение переменных это выражение
```csharp
int x = 3;
int y = 4;
bool b = x == y;
Console.WriteLine(b);
```
Вместо `x` и `y` подставляются их значения: `3 == 4` → `false`. Вывод: `False`.

### 5. Сложное сравнение переменных
```csharp
int x = 3;
int y = 4;
bool b = x * 2 == y + 4;
Console.WriteLine(b);
```
Арифметика выполняется раньше сравнения: `((x * 2) == (y + 4))` → `(6 == 8)` → `false`. Вывод: `False`.

### 6. Перезапись `bool` переменной
```csharp
bool a = 1 > 2;
a = 3 == 3;
Console.WriteLine(a);
```
Сначала `a = false` (`1 > 2`), потом перезаписывается результатом `3 == 3` → `true`. Вывод: `True`.

### 7. Передача `bool` переменной функции
```csharp
bool a = true;
F(a);

static void F(bool x)
{
    Console.WriteLine(x);
}
```
Значение `a` (`true`) копируется в параметр `x`, функция его печатает. Вывод: `True`.

### 8. Передача `bool` выражения функции
```csharp
F(5 > 3);
```
Аргумент `5 > 3` вычисляется до вызова, в `flag` попадает результат `true`. Вывод: `True`.

### 9. Возвращение `bool` значения
```csharp
bool result = F();
Console.WriteLine(result);

static bool F()
{
    return true;
}
```
Возвращаемый тип `F` — `bool`, результат вызова `true` сохраняется в `result`. Вывод: `True`.

### 10. Возвращение `bool` выражения
```csharp
bool result = IsGreater(5, 3);

static bool IsGreater(int a, int b)
{
    return a > b;
}
```
`return` вычисляет выражение `a > b` → `5 > 3` → `true` и возвращает его. Вывод: `True`.

### 11. Сравнение логических значений
```csharp
bool a = true;
bool b = false;
bool c = a == b;
```
`==` работает и с `bool`: `true == false` → `false`. Вывод: `False`.

### 12. Оператор `!`
```csharp
bool a = false;
bool b = !a;
```
`!` меняет значение на противоположное: `!false` → `true`. Вывод: `True`.

### 13. Оператор `&&`
```csharp
bool a = true;
bool b = false;
bool c = a && b;
```
`&&` дает `true`, только если оба операнда `true`. `true && false` → `false`. Вывод: `False`.

### 14. Тонкости оператора `&&` (1)
```csharp
bool result = A() && B(); // A вернет true, B вернет true
```
`A()` вернула `true` — результат еще не известен, поэтому вызывается и `B()`.
```
A
B
```
`result = true`.

### 15. Тонкости оператора `&&` (2)
```csharp
bool result = A() && B(); // A вернет true, B вернет false
```
`A()` вернула `true`, значит `B()` тоже вызывается. `true && false` → `false`.
```
A
B
```
`result = false`.

### 16. Тонкости оператора `&&` (3)
```csharp
bool result = A() && B(); // A вернет false
```
`A()` вернула `false` — при `&&` результат уже точно `false`, поэтому `B()` **не вызывается** (lazy evaluation).
```
A
```
`result = false`.

### 17. Тонкости оператора `||`
```csharp
bool result = A() || B(); // A вернет true
```
`A()` вернула `true` — при `||` результат уже точно `true`, поэтому `B()` **не вызывается**.
```
A
```
`result = true`.

Для сравнения в программе есть дополнительный пример: если `A()` возвращает `false`,
то при `||` вызывается и `B()` — печатается `A`, `B`.
