# Лабораторная работа 5. Функции с параметрами

Задание: https://antonc9018.github.io/uniCourse_csharp/ru/labs/basic/functions/

Каждый пример — отдельная функция `TaskNN` в [Program.cs](Program.cs), внутри нее исходный код примера.
Строки `проверка: ...` добавлены, чтобы увидеть значения переменных.

```bash
dotnet run        # все примеры, кроме 9
dotnet run -- 9   # пример 9 отдельно (программа падает со Stack overflow)
```

## Концепты

- **Функция** — именованная группа инструкций.
- **Определение функции** — место, где заданы ее сигнатура и тело (`static int F(int a, int b) { ... }`).
- **Вызов функции** — `F(1, b)`: выполнение переходит в тело функции, а после `return` (или конца тела) возвращается обратно.
- **Параметр** — локальная переменная функции, объявленная в скобках (`int a`).
  **Аргумент** — выражение при вызове, значение которого копируется в параметр.
- **Возвращаемое значение** — результат вызова, задается `return`. `void` — функция ничего не возвращает.
- **Сигнатура** (интерфейс функции) — возвращаемый тип, имя и типы параметров: `int F(int, int)`.

| 2 | да | `a`; во время `F` еще локальная `a` из `F` | `a = 5` |
| 3 | **нет**, CS0103 | — | — |
| 4 | да | `a`; во время `F` еще параметр `b` | `a = 5` |
| 5 | да | `a`; во время `F` еще параметр `a` из `F` | `a = 5` |
| 6 | да | `b`; во время `F` еще `a`, `b` из `F` | `b = 6` (результат `F` потерян) |
| 7 | да | `b`, `s`; во время `F` еще `a`, `b` из `F` | `b = 7`, `s = 7` |
| 8 | да | `b`, `s`; во время каждого из 3 вызовов `F` еще по 2 параметра | `b = 6`, `s = 15` |

| 11 | да | `a`, `b`; во время `F` еще `x` | `a = 2`, `b = 1` |

## Подробно

### 1. Две разные переменные
```csharp
int a = 5;
F();

static void F()
{
    int b = 6;
}
```
В основной программе создается `a = 5`. При вызове `F` в стеке создается еще одна переменная `b = 6`.
Когда `F` завершается, `b` перестает существовать: из основной программы к ней не обратиться.
Всего одновременно существует максимум 2 переменные, в конце — только `a = 5`.

### 2. Две переменные с тем же именем
```csharp
int a = 5;
F();

static void F()
{
    int a = 6;
}
```
То же самое, что в примере 1: `a` внутри `F` — это **другая** ячейка памяти, просто с тем же именем.
`a = 6` внутри `F` не трогает `a` основной программы. В конце `a = 5`.

### 3. Использование переменной после завершения функции
```csharp
int a = 5;
F();
b = 7;

static void F()
{
    int b = 6;
}
```
```
error CS0103: Имя "b" не существует в текущем контексте.
```
Не компилируется: `b` — локальная переменная `F`, в основной программе такой переменной нет.

### 4. Перезапись переданной переменной
```csharp
int a = 5;
F(a);

static void F(int b)
{
    b = 6;
}
```
При вызове для параметра `b` создается локальная переменная, и в нее **копируется** значение аргумента (`5`).
`b = 6` меняет только эту копию. В конце `a = 5`.

### 5. Перезапись переданной переменной с тем же именем
```csharp
int a = 5;
F(a);

static void F(int a)
{
    a = 6;
}
```
То же, что в примере 4: параметр `a` — отдельная локальная переменная `F`, не связанная с `a` снаружи.
В конце `a = 5`.

### 6. Два параметра (1)
```csharp
int b = 6;
F(1, b);

static int F(int a, int b)
{
    return a + b;
}
```
`F` возвращает `7`, но результат никуда не сохраняется и просто теряется. В конце `b = 6`.

### 7. Два параметра (2)
```csharp
int b = 6;
int s = F(1, b);
b = s;
```
`F(1, 6)` возвращает `7`, он сохраняется в `s`, потом копируется в `b`. В конце `b = 7`, `s = 7`.

### 8. Передача вызова функции параметром
```csharp
int b = 6;
int s = F(F(1, F(2, b)), b);
```
Выражение вычисляется изнутри наружу:
- `F(2, b)` → `F(2, 6)` → `8`;
- `F(1, 8)` → `9`;
- `F(9, b)` → `F(9, 6)` → `15`.

В конце `b = 6`, `s = 15`.

### 9. Функция, вызывающая себя
```csharp
F(1);

static void F(int a)
{
    F(a);
}
```
Компилируется, но каждый вызов `F` создает в стеке новую переменную `a` (копию `a` из предыдущего вызова, то есть `1`)
и снова вызывает `F`. Вызовы никогда не заканчиваются, стек переполняется, и программа падает.
Реальный вывод `dotnet run -- 9`:
```
Stack overflow.
Repeated 261312 times:
--------------------------------
   at Program.<<Main>$>g__F|0_22(Int32)
--------------------------------
```
Процесс завершается с кодом 134. Поймать это исключение нельзя, поэтому в общем запуске пример пропускается.

### 10. Копирование аргументов
```csharp
int a = 1;
F(a + 2);
a = 10;

static void F(int x)
{
    Console.WriteLine(x);
}
```
Сначала вычисляется `a + 2` = `3`, и в `x` передается **результат** `3`. Напечатается `3`.
Изменение `a` после вызова на `x` уже не влияет. В конце `a = 10`.

### 11. Передача параметра, его смена после вызова
```csharp
int a = 1;
int b = F(a);
a = 2;

Console.WriteLine(a);
Console.WriteLine(b);

static int F(int x)
{
    return x;
}
```
При вызове `F(a)`: создается `x`, в него копируется `1`, `return x` делает `1` результатом вызова, `x` исчезает.
Результат `1` записывается в `b`. Потом `a` меняется на `2`, а `b` остается `1`.
Вывод: `2`, `1`.

### 12. Тип результата выражения
```csharp
string s = GetGreeting();
Console.WriteLine(s);

static string GetGreeting()
{
    return "Привет";
}
```
Тип выражения `GetGreeting()` — это возвращаемый тип функции, `string`. Он совпадает с типом `s`.
Вывод: `Привет`.

Если заменить тип `s` на `int`:
```csharp
int s = GetGreeting();
```
```
error CS0029: Не удается неявно преобразовать тип "string" в "int".
```
